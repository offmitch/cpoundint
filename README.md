# Compound Interest Visualizer
link: https://offmitch.github.io/cpoundint/

#Description
This is a tool for getting an idea of the effect of compound interest, laid out simply for anyone to learn how it works.

#Features
- A share price that changes each month (which can be simulated by the user). This share price fluctuates based on a custom formula which aims to mimic most common stock prices
- The ability to buy shares at a user set price.
- A form for simulating monthly payments with a custom investment and length of time.
- Information of how many shares you own, amount invested, your share value, and time passed.
- A separate section for calculating monthly payments over a custom return rate and custom length of time
